# Related Repositories

This repository contains the Solidity contracts for Baby Bank.

The sibling repository `../baby_bank_ops_console` represents an operations
console owned by the same product system. It is intentionally not a dependency:
this contract repo does not import it, build it, or require it at runtime.

The linked repo is useful as context when reviewing issues here because it
documents how operators and off-chain tooling expect to interact with the
contracts.
